# Online Learning Platform Analytics

## Project Overview

This is my graduation project from a Data Analysis Diploma.

The project focuses on analyzing data from an online learning platform to understand student engagement, course performance, feedback, and completion insights.

## Tools & Technologies

- SQL Server
- Power Query
- Python
- Jupyter Notebook
- Power BI

## Project Workflow

1. Data storage and preparation using SQL Server
2. Data transformation using Power Query
3. Data analysis and visualization using Python
4. Interactive dashboard development using Power BI

## Dashboard Pages

### Student Engagement
Analyzes student enrollments, progress, completion rates, enrollment trends, and student performance.

### Course Performance
Analyzes course ratings, progress, duration, and overall course performance.

### Feedback & Completion Insights
Analyzes course feedback, ratings, completion status, and progress.

## Power BI Features

- Drillthrough for course-level analysis
- Interactive slicers
- Tooltips
- Page navigation
- Bookmarks

## Key Insights

- The highest enrollment year was 2023 with 266 enrollments.
- The highest completion rate among the analyzed courses was Excel Data Consolidation at 55.6%.
- Deep Learning Fundamentals had the highest average progress at 58%.
- Python for Data Science had the highest course rating at 4.1.
- The overall average rating was 3.36.
- The overall completion rate was 33.9%.
